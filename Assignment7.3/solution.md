# Assignment 7.3 — Responsive Product Listing

## Theory

A responsive product listing is a web page that displays products in an organized layout and adjusts automatically according to the screen size. In this assignment, I created a responsive product listing using HTML and CSS Flexbox. The listing contains product cards, each displaying an image, product name, price, and button.

### 1\. Product Cards

Product cards are used to display product information in a structured format. I created at least six product cards, each containing an image, name, price, and button to make the listing informative and user-friendly.

### 2\. Display Flex

The CSS property `display: flex` is used to arrange product cards in a flexible layout. It helps align the cards horizontally and makes it easier to manage their positions within the container.

### 3\. Flex Wrap

The `flex-wrap: wrap` property allows product cards to move to the next line when there is insufficient space in the container. This helps maintain a neat layout on smaller screens.

### 4\. Gap Property

The `gap` property adds space between product cards. It improves the visual appearance of the listing and prevents the cards from appearing crowded.

### 5\. Flex Grow

The `flex-grow` property determines how much a flex item can grow to occupy available space in the container. It helps distribute extra space among product cards.

### 6\. Flex Shrink

The `flex-shrink` property controls how much a flex item can shrink when the available space becomes limited. It helps the layout fit within the container without unnecessary overflow.

### 7\. Flex Basis

The `flex-basis` property defines the initial size of a flex item before the remaining space is distributed. It helps control the initial width of each product card.

### 8\. Responsive Design

Responsive design ensures that a website works properly on devices with different screen sizes, such as desktops, tablets, and mobile phones. By using Flexbox and wrapping, I made the product cards adjust to the available space and move to the next row when necessary.

### 9\. Testing at Different Screen Sizes

I tested the product listing at desktop and mobile screen widths to check whether the cards displayed correctly, maintained proper spacing, and adapted to smaller screens.

## Conclusion

In this assignment, I created a responsive product listing using HTML and CSS Flexbox. I designed at least six product cards containing images, names, prices, and buttons. I used `display: flex`, `flex-wrap`, and `gap` to arrange the cards and experimented with `flex-grow`, `flex-shrink`, and `flex-basis` to understand flexible layouts. This assignment helped me learn how to create responsive and well-organized product listings for different screen sizes.
